# To-Do List

A simple, single-page to-do list app built with vanilla HTML, CSS, and JavaScript — no frameworks, no dependencies.

## Features

- Add new tasks
- Mark tasks as complete
- Delete tasks
- Daily motivational quote
- Tasks saved to `localStorage`

## Tech Stack

- HTML5
- CSS3
- JavaScript (DOM manipulation, event delegation)

## Getting Started

Clone the repo and open `index.html` in your browser — no build step or server required.

```bash
git clone https://github.com/bekwizgobisa321-lgtm/daily-todo-web.git
cd daily-todo-web
```

Then just open `index.html`.
